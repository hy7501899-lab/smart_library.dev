# Smart Library - Frontend

Static HTML/CSS/JavaScript frontend.

## Deploy on Render
1. Create a **Static Site** from this GitHub repository.
2. Set **Root Directory** to `frontend` if using the combined repository.
3. Build Command: leave empty.
4. Publish Directory: `.`.
5. After deploying the backend, edit `config.js` and replace the placeholder URL with the real backend URL, then commit and push.

Do not put Gemini API keys or other secrets in frontend files.
